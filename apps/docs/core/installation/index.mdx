This fork ships as a **single container**: the bundled API and web app plus the libSQL (Turso) database stored on a local file. There is no PostgreSQL sidecar, no external database, and no separate web service.

## Choose your installation method

### Build locally (recommended)

Uses `compose.yml`, which builds the image from `Dockerfile.kaneo`:

1. [Review the compose file](/core/installation/docker-compose)
2. [Configure environment variables](/core/installation/environment-variables) (`cp .env.sample .env`)
3. [Start the services](/core/installation/start-services)

### Prebuilt image

`compose.remote.yml` pulls the image published by `.github/workflows/publish.yml` from GHCR instead of building locally. Same steps, with `docker compose -f compose.remote.yml up -d`.

## Requirements

- Docker 20.10+ and Docker Compose V2
- 2GB RAM minimum
- 10GB disk space
- A directory writable by the container user (uid 1001) for the database

**Supported platforms:** Linux, macOS, Windows (WSL)
